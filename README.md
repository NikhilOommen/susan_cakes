# Susan's Cakes website
Plain HTML/CSS/JS, no build step. Uses ES modules, so it must run on a web server (Netlify works; locally use `python3 -m http.server`).

| Change | File |
|---|---|
| UPI ID, WhatsApp, cut-off date, texts | data/config.js |
| Cakes, sizes, prices | data/cakes.js |
| QR / logo / photos | images/ (upi-qr.png, logo.png, cake photos) |
| Colours, fonts | css/tokens.css |
| Layout and animations | css/styles.css |
| Card templates | js/components.js |
| Icons | js/icons.js |
